# 数据、备份与升级

[返回快速开始](../README.zh_CN.md) · [English](data-and-upgrades.md)

## 数据位置

设置、频道、规则及发现统计保存在程序旁的 `data/bilistream.db`。配置与登录信息加密保存，在本机重启时自动解锁；日常修改通过 Web UI 完成。可用 `BILISTREAM_DATA_DIR` 指定数据目录，用 `BILISTREAM_KEY_FILE` 指定目录**之外**的受限密钥文件。

请保留原密钥，单独复制数据库不能用于换机恢复。不要删除数据库的 `-wal`、`-shm` 文件。图片继续保存在缓存目录，`webui/` 为页面资源。

## 备份与恢复

在「系统设置 → 数据与备份」下载密码保护的备份，另行保管备份密码。新安装可在设置向导中点击「已有备份？直接恢复」。备份不包含面板密码和网页登录会话。恢复会保留目标安装的密码选择；全新安装需在本机设置面板密码，或首次启动时提供初始密码。

备份从不包含集群身份。从集群成员导出的备份恢复后不属于任何集群，监控全部关闭；之后请重新新建或加入集群。已在集群中或正在准备加入的服务器不能恢复备份。

## 升级

切换新版前先停止旧进程。升级时自动导入原有 JSON 和 Cookie 文件；缺少新设置项的旧配置也可直接升级，新增设置使用默认值。验证加密恢复副本后才移除程序目录内的旧数据；外部 Cookie 文件不会删除。

多服务器各自保存数据库和密钥。新旧集群版本不能同时运行：升级前停止所有服务器，为每台服务器做一份物理备份（停止后的数据目录、密钥文件、程序和启动命令）。之后全部升级，并按[从共享令牌集群升级](advanced-settings.zh_CN.md#从共享令牌集群升级)重新建立集群。

## 回退旧版

先停止服务，再用**新版**程序运行：

```bash
./bilistream --export-legacy ./downgrade-data
```

新目录内是供旧版使用的明文配置和凭据，用完请删除。

旧版无法读取 Web UI 保存的面板密码。回退前停止服务；启动旧版远程监听时，必须明确提供 `--password-file` 或 `BILISTREAM_PASSWORD`，也可先以本机地址启动。仅回退程序文件不能保留新版的密码保护。明文导出也不包含面板密码；保留原数据库与密钥，以便返回新版。

服务器新建、准备加入或加入集群后，或保存着已暂停的旧集群配置时，旧版会拒绝打开它的数据库。此类服务器的明文导出不属于任何集群，监控全部关闭。回退集群时，停止所有服务器，再一起恢复各自在升级前做的物理备份。不要让新旧版本在同一集群中运行，也不要只替换部分服务器的程序。
